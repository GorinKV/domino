# 🁫 Домино

Классическая игра «Домино» для двух игроков (человек против ИИ), написанная на чистом HTML/CSS/JavaScript. Без библиотек, без сборки, без зависимостей — всё в одном файле.

![License](https://img.shields.io/badge/license-MIT-green)

## 🎮 Как играть

Открой игру в браузере — и вперёд.

```
http://<адрес-сервера>/domino/
```

Или просто открой `index.html` двойным кликом (работает и локально, без сервера).

## ✨ Возможности

- 🎲 **Полный набор костяшек** — 28 штук, от 0-0 до 6-6.
- 🤖 **ИИ-соперник** — жадная стратегия: сбрасывает в первую очередь «тяжёлые» костяшки.
- 🎯 **Правильный старт раунда** — начинает игрок со старшим дублем (6-6 → 5-5 → …).
- 🎰 **Базар** — если хода нет, берёшь из колоды, пока не появится играбельная костяшка.
- 🐟 **«Рыба»** — партия автоматически завершается, если оба игрока не могут ходить.
- 📊 **Подсчёт очков** — по сумме костяшек на руках проигравшего.
- 🔄 **Многораундовая игра** — счёт и номер раунда растут.
- 💾 **Сохранение прогресса** — через `localStorage`, не сбрасывается при закрытии браузера.
- 🎬 **Анимации** — появление костяшек в руке и на столе.
- 📱 **Мобильный дизайн** — оптимизировано под смартфоны.

## 🛠️ Технологии

- **HTML5** — разметка
- **CSS3** — анимации (`@keyframes`), flexbox, grid для точек на костяшках
- **Vanilla JavaScript** — вся игровая логика
- **localStorage** — сохранение счёта

Никаких фреймворков, никаких сборщиков. Просто открой файл.

## 🚀 Деплой

Просто положи `index.html` в любую папку, которую раздаёт твой веб-сервер (nginx, apache, Caddy). Например:

```nginx
location ^~ /domino/ {
    alias /var/www/domino/;
    index index.html;
    try_files $uri $uri/ /domino/index.html;
}
```

Статика, никакого бэкенда.

## 🎯 Правила домино (кратко)

1. Каждому игроку раздаётся по **7 костяшек**, остальные — в **базар**.
2. Первым ходит игрок со **старшим дублем**.
3. Костяшки кладутся так, чтобы **числа на стыках совпадали**.
4. Если хода нет — игрок **берёт из базара**, пока не появится играбельная костяшка.
5. Если **базар пуст** и ходов нет — ход **пропускается**.
6. Если оба пропустили ход — **«рыба»**, подсчитываются очки.
7. Побеждает тот, кто **первым сбросит все костяшки** (или у кого меньше очков при «рыбе»).
